# Styled by People

A mid-market styling game: players style real, affordable outfits for real-life briefs, other players vote A vs B, and every look can be shopped. "Styled by People" is a working name.

**Private repo.** It contains third-party product photos used only for an internal mockup.

## Branches

| Branch | What's in it |
|---|---|
| `main` | This README. Reserved for the product build later |
| `project-materials` | Concept, research, pitch report, mockup and images |

## Start here

Read `context.md` on the `project-materials` branch. It has the concept, game decisions, business model, research findings, plan and open questions.
